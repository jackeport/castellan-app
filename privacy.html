Castellan privacy policy

Last updated 23 November 2026.

Who uses it

Castellan is a private tool used only by its owner, with the owner's own Google accounts. It is not offered to anyone else.

What Google data it accesses

  • Google Calendar: reads events (read-only), and creates and updates events only in one calendar named "Castellan" that it creates itself. It cannot change any other calendar.
  • Google Tasks: reads tasks and due dates (read-only).
  • Google Drive: reads file metadata only (names, types, when a file was edited or viewed); never file contents (read-only).
  • The account's email address, to tell accounts apart.

Where the data goes

All data is stored only on the owner's own computer, in a local database. It is not sent to any server run by Castellan (there is none), not sold, not shared with anyone, and not used for advertising. Sign-in tokens are kept in the Windows Credential Manager on that computer.

Castellan's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local database removes all stored data.

Contact

Through the support email shown on the Google sign-in screen.
